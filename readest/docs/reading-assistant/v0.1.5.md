# Reading Assistant 集成 v0.1.5

- 日期：2026-11-08
- 状态：已完成
- 上游 Readest 版本：保持 `0.12.x`

## 交付

- 在 `src/services/readingAssistant/client.ts` 中新增 `registerReadingAssistant`，
  调用后端 `POST /api/auth/register` 完成账号注册后自动执行 `loginReadingAssistant`
  获取并持久化本地 JWT 会话。
- 在 `ReadingAssistantForm.tsx` 中新增 `Register`（注册）按钮，支持新用户在客户端界
  面上直接输入服务地址、用户名与密码完成注册并连接远程书库。

## 边界

本版本仅补齐客户端原生账号注册与自动登录闭环，不修改后端认证接口契约。
