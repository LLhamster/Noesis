# Reading Assistant 集成 v0.1.7

- 日期：2026-11-08
- 状态：已完成
- 上游 Readest 版本：保持 `0.12.x`

## 交付

- 新增 `src/services/readingAssistant/userState.ts`，封装面向当前登录账号的 CFI 阅
  读进度查询/上报（`GET / POST /api/user/books/{bookId}/progress`）与个人划词笔记增
  删查（`GET / POST / DELETE /api/user/.../annotations`）。
- 在 `ReadingAssistantChat.tsx` 中接入个人进度与笔记同步：打开书籍时自动从当前登录
  账号拉取 `cfi` 并恢复阅读位置，翻页时将最新 `cfi` 与章节序号上报至个人账号；支持将
  当前划词与心得一键保存至个人账号，并点击已存笔记跳回对应 `cfi` 位置。

## 边界

本版本实现阅读进度（CFI）与划词笔记按后端 `userId` 隔离存储，Google 云端书籍自动
匹配后端 `bookId` 与 XML EPUB 兼容属于 `v0.1.8`。

## 验证

- Reading Assistant 会话、书库、AI、用户状态与阅读面板共 6 个测试套件（18 项单元测
  试）全部通过。
- 涉及文件通过 Biome 格式化与静态检查。
