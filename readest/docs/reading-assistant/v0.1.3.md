# Reading Assistant 集成 v0.1.3

- 日期：2026-11-07
- 状态：已完成
- 上游 Readest 版本：保持 `0.12.x`

## 交付

- 在 `src/utils/access.ts` 中将 `CLOUD_SYNC_REQUIRES_PREMIUM` 设为 `false`，解除
  Google Drive 云同步对 Readest Cloud 登录与付费订阅的门控限制。
- 未登录 Readest Cloud 或处于 `free` 计划时，“设置 → 集成 → 云同步 → Google
  Drive”不再显示 `Premium` 角标，点击可直接进入 Google Drive 配置页，已配置账号可
  直接在列表行内切换同步开关，且 `resolveCloudSyncGate` 保持 `paused: false`。

## 边界

本版本仅解除云同步会员门控，不改动 Google OAuth 凭据注入、文件同步协议或后端接
口。

## 验证

- 云同步门控与集成面板定向测试共 6 个测试套件（95 项测试）全部通过。
- 涉及文件通过 Biome 代码规范与格式化检查。
