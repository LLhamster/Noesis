# Reading Assistant 集成 v0.1.4

- 日期：2026-11-07
- 状态：已完成
- 上游 Readest 版本：保持 `0.12.x`

## 交付

- 在 `src/services/runtimeConfig.ts` 与 `buildGoogleDriveProvider.ts` 中支持通过运行
  时配置与构建环境变量（`GOOGLE_CLIENT_ID` / `NEXT_PUBLIC_GOOGLE_CLIENT_ID`、
  `GOOGLE_WEB_CLIENT_ID` / `NEXT_PUBLIC_GOOGLE_WEB_CLIENT_ID`）注入 Google OAuth
  客户端 ID，自动去除首尾空白并在未配置时回退至内置官方 Client ID（与
  `tauri.conf.json`、`Info-ios.plist`、`AndroidManifest.xml` 中的反向 DNS 回调
  scheme 一致）。
- 在 `.env.local.example`、`.env.tauri.example` 与 `.env.web.example` 中补充
  Google Drive OAuth 环境变量配置说明。
- 在 `webTokenStore.ts` 中将 Web 端 OAuth 令牌同时持久化至 `sessionStorage` 与
  `localStorage`，使未过期的访问令牌在跨标签页或重启浏览器窗口后依然有效，断开连接
  时同步清理两处存储。

## 边界

本版本完成 OAuth 凭据解析、环境变量模板与客户端令牌持久化加固，不改变云端目录结
构与后端接口。

## 验证

- Google Drive 与 OAuth 21 个测试套件（121 项单元测试）全部通过。
- 涉及文件通过 Biome 格式化与静态检查。
