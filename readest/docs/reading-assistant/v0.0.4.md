# Reading Assistant 集成 v0.0.4

- 日期：2026-11-03
- 状态：已完成
- 上游 Readest 版本：保持 `0.12.x`

## 交付

- “设置 → 集成 → 内容来源”新增 Reading Assistant 入口。
- 支持配置服务地址、账号登录、会话恢复、到期清理、在线校验和退出。
- 服务地址和 JWT 仅保存在当前设备；不保存密码，不替换 Readest Cloud 账号。

本版本只建立认证连接。远程书库、文件缓存和原生阅读属于 v0.0.5。
